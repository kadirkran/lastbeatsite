# Last Beat website (marketing, support, privacy)

Static site published with GitHub Pages from the public repo `kadirkran/lastbeatsite`.

- Marketing URL: https://kadirkran.github.io/lastbeatsite/
- Support URL:   https://kadirkran.github.io/lastbeatsite/support.html
- Privacy URL:   https://kadirkran.github.io/lastbeatsite/privacy.html

Publish: GitHub repo > Settings > Pages > Source "Deploy from a branch" > branch `main`, folder `/ (root)` > Save.

`build_site.py` regenerates the three pages (contact email, developer name and date are at the top).
